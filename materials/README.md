# Учебник для локальной установки

`math-grade5.epub` — предоставленный пользователем учебник «Математика. 5 класс. Часть 1», 224 страницы. SHA-256: `ba26a79a1ea19f125cdddf694215d952a96941844c559c85903c6fdf472cb35e`.

`math-grade5.json` — распознанный текст, название, предмет, класс и 225 учебных разделов. В нём нет аккаунтов, владельцев, паролей, сессий, сообщений, результатов или тестов. Длинная страница поделена на части. Это результат OCR: сложные формулы и таблицы следует сверять с исходником.

Авторы учебника: Т. А. Алдамұратова, К. С. Байшоланова, Е. С. Байшоланов. [Страница издательства Атамұра](https://free.atamura.kz/?mbdb_book=%D0%BC%D0%B0%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D0%B0-1-%D1%87%D0%B0%D1%81%D1%82%D1%8C). Учебник добавлен в комплект по запросу пользователя; права на него сохраняются за правообладателями.

`npm run setup:local` создаёт локальные аккаунты и устанавливает книгу в местную базу. Владельцем становится местный teacher@edutest.local. Повторный запуск сохраняет существующую книгу и не дублирует разделы. Отдельная установка после удаления — `npm run setup:book`. Исходный EPUB становится доступен для скачивания через приложение после входа. Повторное распознавание не нужно.

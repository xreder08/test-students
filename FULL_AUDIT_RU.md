Авторы: Т. А. Алдамұратова, К. С. Байшоланова, Е. С. Байшоланов. Исходный EPUB — 35 779 164 байта; SHA-256 `ba26a79a1ea19f125cdddf694215d952a96941844c559c85903c6fdf472cb35e`.

Файл состоит из изображений страниц. Импорт выполнен через настоящую форму учителя: все 224 страницы прошли OCR в браузере примерно за 5 минут 20 секунд. Книга сохранена под названием **«Математика. 5 класс. Часть 1 — проверенный учебник»**. В библиотеке 225 разделов: длинная страница разбивается дополнительно. Проверены наличие всех номеров страниц и отсутствие пропущенных страниц. Исходник, распознанный текст и база остаются локальными и не входят в Git.

Проверены чтение страницы, пояснение реального ИИ, создание учительского теста и полный ученический сценарий: чтение → объяснение → «Глава изучена» → автоматический тест → сохранение ответов → завершение → результат у учителя → перезагрузка результата. Большое оглавление проверено на компьютере и экране 390×844.

## Исправления

| Проблема | Исправление и проверка |
| --- | --- |
| Некорректный JSON или null приводил к внутренней ошибке | Ограниченный JSON-парсер и валидация действия: контролируемый HTTP 400; неверный тип содержимого — 415 |
| Лимит JSON зависел от Content-Length | Считаются фактические байты потока; больше 1 МБ — 413, включая запрос без заголовка размера |
| Лишние сегменты адреса могли запускать удаление книги | Разрешены только точные маршруты и методы; DELETE с лишним сегментом возвращает 404 и сохраняет книгу |
| Одновременная регистрация одного email давала HTTP 500 | Атомарная вставка с обработкой конфликта: один ответ 200, второй 409 |
| Ошибки API не запрещали кеширование | Ответы об ошибках содержат private, no-store |
| Короткие разделы с формулами терялись | Сохраняются все непустые разделы; добавлена проверка короткого математического текста |
| OCR оценивал читаемость только по буквам | При оценке учитываются цифры: страницы с числовыми заданиями не теряются по этой причине |
| Groq отклонил JSON теста на настоящем учебнике | Одно ограниченное повторение json_validate_failed, уточнён формат вариантов и пояснений; схема и Zod остаются обязательными |
| Повреждённый успешный ответ провайдера вызывал внутреннюю ошибку | Обработка невалидного JSON и незавершённого ответа с понятной ошибкой 502 |
| Повреждённая multipart-форма давала внутреннюю ошибку | Проверяются формат загрузки и ошибки разбора формы, остаётся ограничение реального размера потока |

## Практические ограничения

Сложные формулы, рисунки и таблицы OCR может прочитать неточно; текст можно проверить и исправить перед сохранением. Проверка структуры теста не доказывает правильность всех учебных фактов ИИ. Файлы до 100 МБ поддерживаются локально; публикация больших загрузок на Vercel требует отдельного файлового хранилища и постоянной облачной базы. Сброс пароля и проверка email пока не реализованы. Эти ограничения не маскируются сообщением «всё без ошибок».

Локальная версия: http://127.0.0.1:3000. Повторяемые команды и настройки расширенных проверок — в README.md. Рабочая ветка: `feature/edutest-web`.

# Результат работы

Обновление 12 октября 2026: скачан учебник математики 5 класса с сайта издательства, все 224 страницы распознаны и сохранены локально. Найденные ошибки загрузки, разбиения, регистрации, маршрутов, лимитов и ответов ИИ исправлены. Итог: 21 unit-тест и 8 браузерных сценариев проходят. Подробные результаты, границы проверки и источник книги — в [FULL_AUDIT_RU.md](FULL_AUDIT_RU.md).

Дата: 9 октября 2026 года.

Flutter-проект сохранён без изменений. Новая версия полностью реализована отдельно в `edutest_web`.

Реализовано: серверная общая библиотека книг; PDF с текстом и сканы со встроенным распознаванием, EPUB, DOCX, TXT/MD; предмет и класс; разбиение на главы; чтение и скачивание исходника внутри платформы; ИИ-репетитор по выбранной главе с объяснениями, примерами и упражнениями; генерация теста после изучения главы; дополнительные ИИ-тесты и ручной редактор для учителя; сохранённые попытки и серверный deadline; разбор ответов; результаты учителя и ученика; адаптивный интерфейс.

Предоставленный Groq-ключ проверен реальным запросом, ответ HTTP 200. Подключена доступная модель `openai/gpt-oss-20b` с разрешения пользователя. Значение ключа находится только в игнорируемой `.env.local`.

Локальный адрес: http://127.0.0.1:3000. Для запуска — START_WEB.bat либо npm run dev. Production-сборка — npm run build / npm run start. Данные входа в локальные аккаунты — LOCAL_ACCESS.md; этот файл не входит в Git.

Проверки: TypeScript; production-сборка; 14 unit-тестов; браузерный сквозной сценарий с реальным Groq, загрузкой книги, ручным тестом, репетитором, автотестом, возобновлением попытки и мобильным экраном; защита от чужого Origin, неверного приглашения, ученического изменения книг, доступа к чужим попыткам и ответов после deadline. npm audit не обнаружил известных уязвимостей. Проверка отслеживаемых файлов не обнаружила встроенных ключей.

Скриншоты и диагностические материалы находятся локально в test-results и исключены из Git. Приватные базы, окружение, локальные пароли, старый встроенный ключ Flutter-проекта в новую ветку не включены.

Веб-приложение загружено в указанный пользователем GitHub-репозиторий https://github.com/xreder08/test-students в ветку `feature/edutest-web`. Перед загрузкой проверены все отслеживаемые файлы: встроенные ключи не обнаружены. После подключения плагина Vercel повторно проверена публикация: список проектов доступен, но запрос настроек интеграций базы в найденной команде возвращает `403 Forbidden` (нет доступа к scope). Локальные Vercel CLI и его авторизация отсутствуют. Публикация остановлена по указанию пользователя при отсутствии доступа; облачная версия не создана. Для Vercel требуется доступ к команде, постоянная Turso/libSQL база и серверные переменные окружения; файловая SQLite на Vercel намеренно запрещена. Существующие облачные проекты и данные не изменены.

Основные ограничения: файл до 100 МБ локально, до 10 миллионов символов текста и 2000 частей/глав, распознавание сложных формул и таблиц требует проверки учителя, форматирование извлечённого текста упрощается, книги общие для участников одной установки. ИИ-материалы требуют проверки учителя. Подробности настройки, безопасности и ограничения описаны в README.md.

Дополнительно проверены: загрузка учебника больше прежнего лимита 4 МБ с более чем 200 частями; сквозной браузерный сценарий PDF без текстового слоя с локальным OCR на русском, отменой/повторным запуском, просмотром и сохранением текста, ответом реального Groq по распознанной странице и скачиванием исходного PDF без изменений. OCR не делает внешних запросов из браузера. На присланном скриншоте отдельно распознаны приветствие и текст о математике. Проверены мобильный экран и отсутствие горизонтального переполнения.

Исправлен EPUB с изображениями страниц: распознавание выполняется в браузере в порядке spine; поддерживаются относительные пути и XML-префиксы, исключаются метаданные head. Полностью обработан предоставленный пользователем EPUB (224 страницы-картинки); книга сохранена только в локальной базе под названием «Математика. 5 класс. Часть 1», 225 разделов. Проверены реальный ответ ИИ и генерация теста по распознанному тексту. Исходник и распознанный текст не включены в Git. Для большого оглавления добавлена отдельная прокрутка и показ выбранного раздела. Регрессионная проверка сканированного и текстового EPUB проходит в браузере.

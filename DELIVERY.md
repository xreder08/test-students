# Результат работы

Дата: 9 октября 2026 года.

Flutter-проект сохранён без изменений. Новая версия полностью реализована отдельно в `edutest_web`.

Реализовано: серверная общая библиотека книг; PDF с текстом, EPUB, DOCX, TXT/MD; предмет и класс; разбиение на главы; чтение и скачивание исходника внутри платформы; ИИ-репетитор по выбранной главе с объяснениями, примерами и упражнениями; генерация теста после изучения главы; дополнительные ИИ-тесты и ручной редактор для учителя; сохранённые попытки и серверный deadline; разбор ответов; результаты учителя и ученика; адаптивный интерфейс.

Предоставленный Groq-ключ проверен реальным запросом, ответ HTTP 200. Подключена доступная модель `openai/gpt-oss-20b` с разрешения пользователя. Значение ключа находится только в игнорируемой `.env.local`.

Локальный адрес: http://127.0.0.1:3000. Для запуска — START_WEB.bat либо npm run dev. Production-сборка — npm run build / npm run start. Данные входа в локальные аккаунты — LOCAL_ACCESS.md; этот файл не входит в Git.

Проверки: TypeScript; production-сборка; 9 unit-тестов; браузерный сквозной сценарий с реальным Groq, загрузкой книги, ручным тестом, репетитором, автотестом, возобновлением попытки и мобильным экраном; защита от чужого Origin, неверного приглашения, ученического изменения книг, доступа к чужим попыткам и ответов после deadline. npm audit не обнаружил известных уязвимостей. Проверка отслеживаемых файлов не обнаружила встроенных ключей.

Скриншоты и диагностические материалы находятся локально в test-results и исключены из Git. Приватные базы, окружение, локальные пароли, старый встроенный ключ Flutter-проекта в новую ветку не включены.

Веб-приложение загружено в указанный пользователем GitHub-репозиторий https://github.com/xreder08/test-students в ветку `feature/edutest-web`. Перед загрузкой проверены все отслеживаемые файлы: встроенные ключи не обнаружены. После подключения плагина Vercel повторно проверена публикация: список проектов доступен, но запрос настроек интеграций базы в найденной команде возвращает `403 Forbidden` (нет доступа к scope). Локальные Vercel CLI и его авторизация отсутствуют. Публикация остановлена по указанию пользователя при отсутствии доступа; облачная версия не создана. Для Vercel требуется доступ к команде, постоянная Turso/libSQL база и серверные переменные окружения; файловая SQLite на Vercel намеренно запрещена. Существующие облачные проекты и данные не изменены.

Основные ограничения: файл до 100 МБ локально, до 10 миллионов символов текста и 2000 частей/глав, OCR для сканов не включён, форматирование извлечённого текста упрощается, книги общие для участников одной установки. ИИ-материалы требуют проверки учителя. Подробности настройки, безопасности и ограничения описаны в README.md.
